# Testing con Java (JUnit 4.13.2)

Pruebas unitarias basadas en el *Curso Completo de Testing y Clean Code con Java* (ATL Academy).

## Ejercicios
| Clase | Pruebas |
|---|---|
| `MoneyUtil` | `MoneyUtilTest` – formato de moneda, redondeo, negativos, euros y símbolo nulo |
| `FizzBuzz`  | `FizzBuzzTest` – múltiplos de 3, de 5, de 15 y números normales |

## Tecnologías
- Java 17+
- JUnit **4.13.2**
- Maven

## Ejecutar las pruebas
    mvn test

Resultado: `Tests run: 10, Failures: 0, Errors: 0` – **BUILD SUCCESS**
